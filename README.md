# homebrew-cc-sesh

Homebrew tap for [cc-sesh](https://github.com/Wingsdh/cc-sesh) — a fork of [sesh](https://github.com/joshmedeski/sesh) with built-in Claude Code live status in the picker.

## Install

```sh
brew install Wingsdh/cc-sesh/cc-sesh
```

The formula in this repo is auto-updated by [GoReleaser](https://goreleaser.com) on every cc-sesh release. Do not edit it by hand.
